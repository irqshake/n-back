Streams

Pick any combination of streams. Each active stream gets its own response key.

Spatial audio plays a short tone hard into the left or right ear only. A match is the same ear repeating N steps later — the tone itself never changes. With Audio on as well, the spoken word itself is panned hard to that ear by a bundled offline voice and no beep is played.

Relational mode offers Audio and Visual. Each runs its own sequence of numbers from the range below — Audio speaks them, Visual shows them. Respond when the gap between this number and the one N steps back equals the gap between the previous number and the one N steps before it. With N = 2, the run 1 4 3 6 is a target. Gaps use the absolute difference. Executive mode in the Configuration card swaps this for a simpler rule — one more than the number N steps back.

Feedback

Buttons flash green only for a correct hit. They flash red for both kinds of error: a false alarm (pressed with no match) and a missed match (matched, but no press). Turn any feedback off here.
